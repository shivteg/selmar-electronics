# Selmar Electronics 🇿🇲⚡

> **Ndola's #1 Electronics Store** — Vitanda Street, Yengwe, Ndola, Copperbelt Province, Zambia.

A stunning, fully interactive electronics website for **Selmar Electronics** built with pure HTML5, CSS3, and Vanilla JavaScript — zero frameworks, lightning fast.

---

## 🌟 Features

| Feature | Details |
|---|---|
| **🎨 Animated Loader** | Full-screen brand loader with progress bar |
| **🖱️ Custom Cursor** | Magnetic custom cursor with hover effects |
| **✨ Particle Canvas** | Animated connected particle network in hero |
| **🏷️ Live Ticker** | Scrolling news/promo ticker strip |
| **🛍️ Product Grid** | 16 products with filter tabs (TVs, Phones, Appliances, Audio, Laptops) |
| **💬 WhatsApp Enquiry** | One-click WhatsApp enquiry per product |
| **⏱️ Countdown Timer** | Real-time sale countdown |
| **📊 Counter Animation** | Animated stats (500+ products, 10K+ customers) |
| **⭐ Testimonials** | 6 real-style customer reviews |
| **🗺️ Google Maps** | Embedded location map with directions |
| **🔍 Search Overlay** | Full-screen search with quick tags |
| **📱 Fully Responsive** | Mobile-first, works on all screen sizes |
| **🎢 Scroll Animations** | AOS-style fade-in with Intersection Observer |
| **🔝 Back to Top** | Smooth-scroll button with animation |
| **🌙 Dark Theme** | Sleek dark UI with neon cyan/orange accent |

## 📦 Tech Stack

- **HTML5** – Semantic markup, SEO meta tags
- **CSS3** – Custom properties, animations, Grid, Flexbox
- **Vanilla JS** – Canvas API, IntersectionObserver, Web Animations
- **Lucide Icons** – Clean icon set via CDN
- **Google Fonts** – Inter + Orbitron
